About Our Project

Medicine Recommendation System using AI & Data Science

Project Overview

The Medicine Recommendation System is an AI-powered healthcare assistant that suggests appropriate medications based on symptoms entered by users. It aims to assist individuals in identifying possible treatments before visiting a doctor, especially in remote or underserved areas.

Users can type or speak their symptoms (e.g., fever, headache, cough), and our system uses machine learning models to provide potential medicine recommendations. This makes healthcare guidance more accessible, fast, and personalized.

Key Features

  • Symptom-based medicine recommendation
  • Real-time prediction
  • User-friendly interface

Technologies Used

  • Python (Pandas, NumPy, Scikit-learn)
  • HTML, CSS, Bootstrap for frontend
  • Jupyter Notebook for development
