# 💊 Medicine Recommendation System

This is a Flask-based web application that recommends medicines based on user input such as symptoms or diseases. It uses CSV-based medical datasets and machine learning techniques to make accurate suggestions.

## 🚀 Features

- 🔍 Predicts diseases based on user input
- 💊 Recommends medicines accordingly
- 📁 Uses real-world medical data in CSV format
- 🧠 Integrates machine learning model for predictions
- 🌐 Flask web interface with modern UI
  

## 🛠️ Technologies & Libraries Used

- Python
- Flask
- Pandas
- NumPy
- scikit-learn
- HTML / CSS / Bootstrap (for frontend)
- Jinja2 (Flask templating)
- OpenAI API (for smart chatbot, if used)

## 🗂️ Dataset

The application uses CSV datasets containing:
- Disease names
- Symptoms
- Recommended medicines
- Additional medical info (as needed)

> Note: Ensure the dataset is cleaned and formatted properly for best results.
